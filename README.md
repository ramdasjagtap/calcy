# calcy

A simple calculator for the browser, made with HTML, CSS and JavaScript.

It handles digits, `+`, `-`, `x` and `÷`, `=`, clear (`C`) and backspace (`←`).

| File | What it does |
|---|---|
| `calculator.html` | The calculator layout and buttons |
| `calculator.css` | Styling |
| `calculator.js` | Button handling and the arithmetic |

## Try it

Open `calculator.html` in a browser.
